O CSS foi usado para deixar o portfólio mais organizado e bonito.
O body define a fonte, cor de fundo, cor do texto e espaçamento das linhas.
O margin cria espaço externo e o padding cria espaço interno nos elementos.
As propriedades border e border-radius criam bordas e deixam os cantos arredondados.
O display: flex e o gap organizam os cards e os elementos do menu.
O :hover muda a aparência dos botões, links e cards quando o mouse passa por cima.
O @media adapta a página para telas menores, como celulares.

Aula 10 - Portfólio responsivo
As classes do CSS foram adicionadas ao HTML, que antes não as usava.
O cabeçalho, o menu, a lista de conhecimentos e os cards usam Flexbox com flex-wrap.
Os cards de projetos usam flex: 1 1 280px e ficam com 3, 2 ou 1 por linha conforme o espaço.
O main tem max-width para o texto não ficar largo demais no desktop.
@media (max-width: 900px): cabeçalho em coluna e centralizado.
@media (max-width: 600px): cards em uma coluna, menu em botões, tabela em blocos e menos espaçamento.
